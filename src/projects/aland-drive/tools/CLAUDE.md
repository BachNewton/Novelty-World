# Åland Drive: tools and labs

The headless tools that measure and check the game, and the dev pages built on the real game. Paths are relative to the project's folder, `src/projects/aland-drive/`; the project's own `CLAUDE.md` there is the overview and says where everything else is written down.

## Tools

The tools run against local tiles, never the real host: `tools/serve-tiles.mjs` serves a folder of them and counts the bytes it sent, and a page takes it with `?tiles=local:<port>`. `tools/look.mjs` takes a screenshot from any place on the map. `tools/shader-count.mjs` counts what a cold page compiles, every WebGPU shader module and pipeline from the device's own calls, grouped by what each pipeline's vertex shader reads: the same on every run, so a change to the start-up compile is judged by it. A `select` in a shader that chooses between anything but plain values is written by three as two branches, each building its own copy of what both share, so a blend by a 0-or-1 weight is used instead where both sides are worked out anyway. Three more ways a shader is compiled more than it needs: TSL writes a function's whole body at each place its result is read, so a function whose struct is read field by field is read once, into what uses all of it (the wall's colour and glow were its biggest shader twice over); a node made inside a function's body is a new one each time three builds the material, so an array a material reads is made outside it; and a uniform array is named in the shader by the node it is, so materials alike but for their own copy of a kit's palette are each a pipeline, and a kit's palette is made once (`art/palette.ts`). A planting's lattices are culled by one kernel unless its rule differs by lattice (`byLattice`). `tools/drive.mjs` drives a route the game's own GPS sets (`--gps=<x,z;x,z;...>`) and prints what it did, cost, held and downloaded, held and stepped by hand, or with `--clock` at real speed, which is the one that says whether anything stalled. `tools/landings.mjs` walks the load focus round the world so tiles land over and over, and prints what each cost. `tools/film.mjs` makes a video from one, for judging what moves: it takes over the page's clock and renders each frame a frame's time after the last, so the video plays at real speed however slowly the machine renders, with the boats' clock set where the video starts and, for a ship's slow manoeuvre, sped up on its own (`--speed`); ffmpeg encodes it. `tools/road-check.ts` drives every motor road in the simulation alone, `tools/car-limits.ts` measures every car's grip, braking and pull on a flat test pad (`sim/test-pad.ts`) of each surface in each condition into the table the racers will read (`sim/car-limits.json`), `tools/bridge-check.ts` every span, both ways, and `tools/junction-check.ts` every way through every junction of a tile (see "How rough the roads are" in `pipeline/CLAUDE.md`). The browser tools use headless Playwright with `channel: "chromium"`, because the default headless shell falls back to WebGL2 here.

## Labs

`?junction-lab` is the real game with the hardest junctions of each kind a click away (`render/junction-spots.ts`, `components/junction-lab.tsx`), from above, at a driver's eye or at the wheel, with the car on the approach, to judge a change to the road surface. `?forest-lab` is the forest on its own (`render/forest-lab.ts`, `components/forest-lab.tsx`), on the game's own forest and terrain code and real tiles, to see how its detail works and to judge a change to it. What detail is measured from can be pinned away from the camera, so a tree goes through everything a drive does to it with the view held still. It colours trees by model, by whether they're mid-change and by how far their base slides, finds the worst trees nearby, changes the forest's settings live, and shows how many trees each list drew; `?date=` shows it in that date's season. `render/tile-reads.ts` is what the game and the lab share, so the lab's trees are the game's. `?deer-lab` is `art/deer`'s gallery running live (`art/deer/stage.ts`, `components/deer-lab.tsx`): every kind in every gait, each gait held through its cycle, a doe and her kids crossing a road, the seasons and the speed to judge the gaits by, flown with the free camera.
