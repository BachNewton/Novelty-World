# Åland Drive: the weather

The shared weather. How it is drawn is in `render/CLAUDE.md` (The weather drawn); `docs/TIME-AND-WEATHER.md` holds the climate itself. Paths are relative to the project's folder, `src/projects/aland-drive/`; the project's own `CLAUDE.md` there is the overview and says where everything else is written down.

The weather is shared and drawn from Åland's climate (`climate/`, `docs/TIME-AND-WEATHER.md`): a pure function of the game's calendar (see `time/CLAUDE.md`), read each frame by `climate/feed.ts` with the date, how far through it, the hour and the game days the page's time shows, so everyone in the online world shares it, and `?date=`, `?hour=` and the dev menu's Day move it with the sky. The fronts move by game days, and the road's memory of rain and snow is in game hours, while the season's snow and ice follow the date, about ten days a game day. The dev menu's Weather or `?weather=` holds one instead; a tool's or a test's page draws none and stays dry unless it asks with `?weather`. The render eases towards it (`render/weather.ts`), so a held one blends in as the shared one does, and it is arcade first: it changes how things look and drive, never so far the road is hard to read.
