# Characters

The 12 explorers on the six two-sided character cards. Each trait track lists its 8 values from lowest (next to the skull) to highest; the starting value is in [brackets]. A trait changes by moving along the track, one space per point, so a track can repeat values. Sex is not printed on the cards; it is taken from the pronouns the Traitor's Tome explorers page uses for each explorer, and haunts 20 and 30 depend on it.
